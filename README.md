# WIP-Data-Analyst

# Economic Trend Dashboard 📈
A fully functional Python dashboard that uncovers the Income Vs. Inflation trends in the United States. This dashboard uncovers the relationship among inflation (CPI), median income, and macroeconomic trends dating back to 1984. The focus of this project is to provide a visual representation of the real and nominal incomes and the impacts of the 2008 recession and COVID-19. 

# Overview

This analysis project aims to highlight how income reacts to inflation over time. With financial disasters such as the 2008 recession and the 2020 global pandemic, we can see how these events contributed to America's global recession. This dashboard provides static and interactive visualizations that make these insights even clearer.


## Features 
- Income Vs. Inflation comparison
- CPI trend analysis and normalization
- 2008 & 2020 recession impact and annotations
- Interactive charts using Plotly
